# Elo-Calculator
A lightweight web-based Elo rating calculator built for a school club.

## How it works
This calculator uses a dynamic **K-factor** based on the player's current rating to keep early ratings flexible and higher ratings stable:

| Current Elo Rating | K-Factor |
| :--- | :--- |
| **1000 – 2100** | 32 |
| **2100 – 2400** | 24 |
| **Above 2400** | 16 |


## Installation
* Using github pages: Go to my page on [Github Pages](https://ncgaston15-ctrl.github.io/Elo-Calculator/).
* Or locally: Clone this folder and run 'index.html' in a browser.
